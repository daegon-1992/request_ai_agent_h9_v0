# h5_v0 단계별 실행 프롬프트

이 폴더의 문서는 각 단계를 새 채팅에서 실행하기 위한 복사-실행 프롬프트다.

## 공통 실행 규칙

1. 해당 단계 문서, `../h5_v0_execution_handoff.md`, 프로젝트 루트의 `AGENTS.md`를 모두 읽는다.
2. 인수인계 문서에서 직전 단계가 `완료`인지와 검증 결과를 확인한다. 완료되지 않았으면 구현하지 않고 사유를 기록한다.
3. 현재 단계에서 필요한 파일만 읽고 수정한다. 전체 포맷팅, 범용 리팩터링, 명세 원문 수정, 보류 기능 구현을 하지 않는다.
4. 기능 변경은 해당 단계의 가장 가까운 테스트만 추가·수정·실행한다. 모든 테스트는 Stage 10에서 한 번만 실행한다.
5. 매 단계 종료 시 `python tools/check_encoding.py --changed`, `git diff --check`와 단계 문서가 지정한 테스트를 실행한다.
6. 완료·보류·실패 여부와 검증 결과를 `../h5_v0_execution_handoff.md`에 기록한다.
7. Git 저장소가 존재하고 `AGENTS.md`의 커밋 조건을 모두 만족하면 해당 단계 변경만 커밋한다. 그렇지 않으면 미커밋 사유를 인수인계에 남긴다.

## 단계 순서

`00 → 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10`

단계 순서를 건너뛰지 않는다. 특히 State 원본을 바꾸는 02~06 단계가 완료되기 전에는 미리보기·Word 작업을 시작하지 않는다.
